# Lakes ORM

Description

LakesORM is a modern Object-Relational Mapper (ORM) built specifically for TypeScript developers, designed to simplify PostgreSQL database interactions. Currently in the Staging phase, version 0.1.48 is an actively developed release, focusing on robust data modelling and type safety for complex applications

To install dependencies:

```bash
bun install
```

For Testing install



To build the npm package:

```bash
bun run build
```

To import Lakes ORM

```bash
bun add  @/lakeorm --force
```

This project was created using `bun init` in Bun v1.3.5. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
